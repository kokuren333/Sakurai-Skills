# 『平均と平凡は同じ』：尖った個性の維持と対称性の打破

## Summary
バランス調整において長所を削り短所を補う『平均化』を排し、強烈な強みと明確な弱みを併せ持つ『尖った個性』を保て。

## SOURCE
『平均と平凡は同じだ！』。スマブラSPでは87種類の全ファイターのオンライン勝率が世界規模の実データで47.18%〜51.43%という極めて狭い範囲に収まりつつ、各キャラの長所・短所を強烈に尖らせている。

## GENERALIZED
バランス調整において長所を削り短所を補う『平均化』を排し、強烈な強みと明確な弱みを併せ持つ『尖った個性』を保て。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
短所のない無難なキャラクターばかりになると、対戦の相性や戦術の多様性が失われ、プレイヤーが愛着を持てなくなるため。

## Use with context
- Domains: Fighting, Hero Shooter, MOBA, Action RPG
- Phases: Character Design, Balancing, Patch Tuning
- Trigger: キャラクターやクラス、武器のパラメータ調整・ナーフ/バフの検討時

## Agent questions
- 強すぎるキャラのナーフ時に、そのキャラ一番の『魅力的な強み（長所）』を削ってしまっていないか？
- 弱キャラを強化する際、単に短所を埋めて誰とでも戦える無個性な万能キャラにしていないか？
- 調整の議論がネットの評判（バイアス）だけに引きずられ、実際の勝率データに基づいているか？

## Suggested actions
- キャラクターを調整する際は『長所をさらに伸ばす代わりに、別の短所を明確にする』方針を第一選択とする。
- 全キャラクターの勝率ヒストグラムを作成し、極端な外れ値がないか確認しつつ性能分散を維持する。

## Review criteria
- 全キャラの勝率が健全なレンジ（例：48〜52%）に収まりつつ、操作感や戦術がキャラごとに全く異なっているか。
