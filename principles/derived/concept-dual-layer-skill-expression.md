# 初心者クリア保証と上級者マニアックプレイの両立（二層構造設計）

## Summary
基本操作だけでクリアできる土台を残したまま、任意習得可能な多機能システムを上乗せして上級者の満足度を満たせ。

## GENERALIZED
必須要件（クリティカルパス）は極めて低くシンプルに保ち、選択要件（オプショナルな機能・テクニック）でスキルの差別化と深みを提供する。

## AGENT
初心者に新システムを強制しないことが最重要。UIやチュートリアルで新システムを義務化すると初心者は離脱する。

## Agent questions
- 新機能は『必須化』されていないか？
- 基本アクションのみのプレイヤーと、新機能を極めたプレイヤーの双方が楽しめるか？

## Suggested actions
- 能力なし状態でのクリティカルパス検証テストコード／シナリオを作成する。
- 高度な能力・技の入力難度とリターンを段階的に設計する。

## Review criteria
- コアシステム未使用でもクリア可能であること。
- コアシステム使用時にプレイの多様性と手応えが向上していること。

## Anti-patterns
- 追加した複雑なシステム（属性相性、複雑な派生技等）を使わなければボスにダメージが通らない仕様。
- 初心者が覚えるべき操作リストを序盤に大量提示するチュートリアル。
