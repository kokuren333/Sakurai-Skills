# プロモーション映像の独立エンタメ化と徹底監修

## Summary
販促ムービーは単なる情報告知ではなく、それ単体でシェアされ鑑賞に値する独立したエンターテインメントとして、細部（画角・音・間）まで徹底監修して制作せよ。

## SOURCE
『スマブラX』の「亜空の使者」ムービーが発売前にネットへ流出・拡散され、ゲーム内で見るご褒美にならなかった教訓から、ゲーム途中のムービーをやめ、ネットでシェアされることを前提にした「参戦ムービー」へ舵を切った。 プロットはほぼ全て桜井氏自身が執筆（ホムラ/ヒカリのみモノリスソフトへ委託）。 CGパートはCG制作会社（デジタル・フロンティア等）と絵コンテ、アニマティクス、プリビズの各段階で綿密に打ち合わせし、モデルの解像度向上、エフェクト、効果音・音楽タイミングを1コマ単位で合わせる。 実機パートは開発スタッフ（バンダイナムコスタジオ、マリオクラブ等）がデバッグ・リプレイ機能を駆使し、画角（FOV）やカメラロールを変更して迫力あるカットを撮る。 注意点：堂々とさせる、画角を駆使する、他ファイターとの絡みを増やす、シリアスとコミカルのバランス、音楽の節目に合わせる。

## GENERALIZED
「ゲームの進行を止めるインゲームムービー」を削減し、「自発的に拡散される独立した映像コンテンツ」へ制作リソースを転換する。 映像の品質は「絵コンテ」「アニマティクス」「プリビズ」の各工程における徹底的なディレクションで決まる。

## AGENT
インディーゲームのトレイラー制作でも直結する。単なるゲーム画面の録画ではなく、カメラワーク、画角調整、音楽のビートマッチングを計算し尽くす必要がある。

## Why it matters
高品質な映像は世界的な熱狂（ミームやリアクション動画）を生み出し、爆発的な拡散効果と開発陣へのモチベーションをもたらす。

## Agent questions
- 音楽の節目とアクションのヒット/カット転換がフレーム単位で合致しているか？
- キャラクターの魅力が引き立つ画角（望遠/広角/ロール）が適用されているか？

## Suggested actions
- BGMの波形データを解析し、ビートや拍のタイミング（マーカー）を抽出してカット割りのタイムラインを自動アラインする。

## Review criteria
- アニマティクス段階で尺と構図が確定しており、視線誘導と音ハメが完璧に機能していること。

## Anti-patterns
- ゲーム内カットシーンをそのまま切り貼りしてトレイラーを作る。
- 音楽と映像のカット変わりがズレており、テンポ感が悪い。
- キャラクターが棒立ちで迫力のない画角のまま撮影する。
