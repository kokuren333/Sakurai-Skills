# 非言語的理解を促すグラフィックUIとボタン連打導線

## Summary
言語を読めなくても機能が伝わるようアイコン・イラストを活用し、最速でメインゲームへ到達できる決定ボタン連打導線を保証する。

## GENERALIZED
言語を読めなくても機能が伝わるようアイコン・イラストを活用し、最速でメインゲームへ到達できる決定ボタン連打導線を保証する。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
多言語対応の不備による離脱を防ぎ、ゲーム起動からプレイ開始までのタイム・トゥ・ファン（Time to Fun）を劇的に短縮するため。

## Use with context
- Domains: Information Architecture, Visual Design, UX Flow
- Phases: Concept, UI Flow Design, Visual Prototyping
- Trigger: メインメニューフロー、画面遷移ステート、タイトル画面の設計時

## Agent questions
- 全メニューのデフォルトフォーカスはメインプレイ直行になっているか？
- アイコン単体で機能が判別可能か？

## Suggested actions
- UI遷移ツリーをトラバースし、各画面のDefaultSelectTargetが最短プレイ導線になっているか検査する。
- テキスト非表示モードでのユーザビリティシミュレーション（アイコンのみ表示）を実施する。

## Review criteria
- タイトル画面から決定キー連打（3〜4打鍵以内）でコアゲームプレイへ遷移すること。
- 全主要メニューに機能を表すビジュアル要素が組み合わされていること。

## Anti-patterns
- テキストのみが縦に並び、アイコンが一切存在しないトップメニュー。
- 決定ボタン連打で進むと「お知らせ」や「ショップ」「利用規約」などに吸い込まれてしまう導線設計。

## Tradeoffs and exceptions
- Tradeoff: アイコンやイラストを多用すると画面が賑やかになり、シリアスな世界観やミニマルなデザインと衝突する場合がある。
- Exception: ストーリーのネタバレを含む重要モードの解放演出や、課金・セーブデータ破棄等の確認画面。
