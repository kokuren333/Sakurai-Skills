# マーケティング/ターゲティングの相対化原則（未来の非拘束）

## Summary
ターゲティングやマーケティングは「過去の分析」に過ぎず未来を示すものではないため、新しい企画を立てる際は過度に囚われてはならない。

## SOURCE
企画時や上司へのプレゼンで「ターゲット層を明確にせよ（年齢、性別、嗜好）」とよく言われる。 しかし、ユーザーの境界線は曖昧（可愛いものが好きな高齢者も、ハードな表現を好む子供もいる）。 初代『星のカービィ』は「初心者層」に向けて作ったが、「子供向け」とは一度も言っていない。初心者には大人も子供も男も女も含まれる。 ターゲティング＝標的を定めて企画、マーケティング＝発売後のデータ収集・分析。 これらは「既存のものから想定するデータ」であり「未来を教えてくれるわけではない」。 通った人が多い安全な道（大通り）を追い続けると、平凡・平均的になりかえって売れなくなる。 ファミコン末期〜スーファミ時代に『ドラクエ』『FF』っぽいRPGが山ほど出てレッドオーシャンに飛び込んだのがその例。 「斬新なことをしよう」とする人はいつでも孤独。誰も通ったことがない道を切り拓くからこそ地平が開ける。

## GENERALIZED
ターゲット層を「デモグラフィック属性（年齢・性別）」で規定するのではなく、「プレイスタイルや体験の習熟度（初心者、短い時間で遊びたい人、等）」という軸で規定せよ。 過去データ（競合分析）はリスク回避には役立つが、新規性のあるヒット作を生み出す指針にはならない。

## AGENT
AIがゲーム企画を評価する際、既存の売上データやSteamタグのトレンドだけを根拠に「今売れているジャンルの模倣」を推奨する過ちを強く防止するための重要原則。

## Why it matters
過去のデータに従うだけのゲーム開発は、レッドオーシャンでの過当競争と没個性を招き、結果的に商業的失敗を引き起こす。

## Agent questions
- ターゲット定義が年齢・性別に過度に依存していないか？
- この企画のコアバリューは、過去の市場データの単なる平均値になっていないか？

## Suggested actions
- ターゲット層の定義を「プレイヤーの動機・プレイスタイル（Motivations）」基準にリファクタリングする。
- 競合分析において、既存の類似作と「差別化される未踏の要素」を明確に抽出する。

## Review criteria
- 過去データの模倣ではなく、独自のプレイスタイルや体験価値を提示できていること。

## Anti-patterns
- 企画書で「ターゲット：10代〜20代の男性」と形骸化したデモグラフィック属性を記載して満足する。
- 「データ上RPGが売れているから」と、既存有名作の劣化コピーを量産する。
