# 非プレイ時間の任意スキップ・ポーズの完全保証

## Summary
会社ロゴ、オープニング、イベントデモ、ムービーなど、プレイヤーが操作していない時間は例外なく任意にスキップおよび一時停止できるようにする。

## GENERALIZED
会社ロゴ、オープニング、イベントデモ、ムービーなど、プレイヤーが操作していない時間は例外なく任意にスキップおよび一時停止できるようにする。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
スキップ不可・停止不可の拘束は、リプレイ性の低下、周回プレイの苦痛、日常生活との不調和を生み、現代のユーザーから最も嫌われる要因となる。

## Use with context
- Domains: Cutscene System, Flow Management, Accessibility
- Phases: System Architecture, Scenario/Event Implementation, QA
- Trigger: カットシーン制御、イベント再生コンポーネント、起動シーケンスの実装時

## Agent questions
- このステートでPause/Skipコマンドは受け付けられているか？
- 初回フラグや特定条件でSkipを無効化していないか？

## Suggested actions
- カットシーン制御基底クラスにSkip/Pause用インターフェースを義務付ける。
- 起動時のメーカーロゴ表示コルーチンにAnyKeyでの即時終了処理を挿入する。

## Review criteria
- 起動からタイトル画面までキー入力ですぐ到達できること。
- すべてのカットシーンでポーズメニュー表示およびスキップが正常に発火すること。

## Anti-patterns
- 開発側のエゴで「初回プレイ時はスキップ不可」とフラグ制御すること。
- ムービー中にポーズボタンを押すと、確認なしで即座にシーン丸ごとスキップされてしまう設計。
- セリフ送りボタンを連打した際、テキスト送りではなくイベント全体が吹き飛ぶ設計。

## Tradeoffs and exceptions
- Tradeoff: ストーリー理解度が下がるリスクがあるが、プレイヤーの自由と快適性を優先すべきである。
- Exception: 同期型オンラインマルチプレイ中など、他プレイヤーの同期を破壊する恐れがあるリアルタイム通信部分。
