# ディレクターは”個”（特異な観点と自立的作家性）

## Summary
他人の意見の平均化に逃げず、自身の特異な感覚や観察眼を信じてエッジの立った方向性を打ち出せ。

## SOURCE
名ディレクターたちに共通点はなく、それぞれ全く違う。あえて言うなら『感覚に敏感で、人とは違うものを見ている』。少し変わり者であることはむしろ良い。自身から発する太いアウトプットが必要。

## GENERALIZED
合議制による無難な落とし所を避け、ディレクター個人の独自の視点や感性に基づいたエッジ（差別化要因）をコアコンピタンスとして確立する。

## AGENT
AIがゲームデザインを行う際、既存のヒット作の特徴を無難にブレンドしただけの『平均点ゲーム』を生成する傾向を打破するためのパラメータ。

## Why it matters
全員の意見を取り入れた無難な製品は、誰の心にも刺さらない凡庸な作品となり、激しい市場競争の中で埋没するため。

## Use with context
- Domains: game_direction, creative_concept, art_direction
- Phases: concept, direction, feature_selection
- Trigger: ゲームのコアメカニクス、世界観、またはアートスタイルの基本方針を決定するとき

## Agent questions
- この企画やデザインは、他作品の無難な平均値になっていないか？
- 制作者独自の『人とは違う着眼点・こだわり』がコアシステムに反映されているか？

## Suggested actions
- 提案されたアイデアの中から、最も特異で他に見られない観点（エッジ）を抽出し、それを強調する設計を組む
- 合議によって丸められそうになった仕様に対し、ディレクターの初期コンセプトの尖りを保護する

## Review criteria
- 『他作品のコピペ』ではない独自の感性・フックが明確に存在すること
- 単なる奇抜さではなく、ディレクター自身の強い観察や体験に基づいた説得力があること

## Anti-patterns
- 他社のヒット作の要素をチェックリスト式に全部盛りにして、作品の個性を消滅させる
- チームメンバー全員の顔色を伺い、全員の好みを足して2で割った仕様にする

## Tradeoffs and exceptions
- Tradeoff: 市場の一定層から理解されないリスクを負うが、熱狂的な支持層を獲得できる。
- Exception: 受託開発や知育アプリなど、厳格なクライアントレギュレーションに従うことが主目的のプロジェクト。
