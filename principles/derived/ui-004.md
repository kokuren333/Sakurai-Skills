# テキスト送り速度の主導権開放とセリフ頭出しスキップ

## Summary
字幕の読了速度は音声再生速度を大幅に上回るため、セリフ単位の頭出し送り、早送り、あるいは移動しながら会話を聞けるテンポ維持機構を用意する。

## GENERALIZED
字幕の読了速度は音声再生速度を大幅に上回るため、セリフ単位の頭出し送り、早送り、あるいは移動しながら会話を聞けるテンポ維持機構を用意する。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
テキスト送りのテンポの悪さは、ストーリー主導のゲームにおいて最も強いフラストレーション源となり、会話を読む気力を削ぐ。

## Use with context
- Domains: Dialogue System, Narrative Presentation, UX
- Phases: Scenario System Design, UI Implementation
- Trigger: ダイアログ送り、メッセージウィンドウ、イベント会話の実装時

## Agent questions
- テキスト送り入力でアニメーション待ちが発生していないか？
- ボイス再生停止処理がクリーンに行われているか？

## Suggested actions
- テキストタイパー（一文字ずつ表示する演出）に即時全表示メソッド（SkipTyping）を組み込む。
- 対話コントローラーにNextLine()をバインドし、ボイス破棄と次テキスト表示をアトミックに実行する。

## Review criteria
- ボタン連打でセリフ単位の早送りが破綻なく行えること。
- スキップされたセリフがバックログから確認可能であること。

## Anti-patterns
- ボイスの再生完了までボタン入力を受け付けず、画面遷移をロックすること。
- セリフ送りボタンを押した瞬間に、次のセリフもろともイベント全体をスキップしてしまうこと。

## Tradeoffs and exceptions
- Tradeoff: セリフを飛ばすとキャラクターの繊細な演技やモーションが途切れるが、テンポ感を損なう代償に比べれば許容すべきである。
- Exception: タイミングがゲームプレイの成否に直結する演出（リズムゲームの歌詞や、緊迫したQTE等）。
