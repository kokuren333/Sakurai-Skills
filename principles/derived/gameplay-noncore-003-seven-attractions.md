# ゲーム性（かけひき）以外の面白さの認識と尊重

## Summary
ゲーム性（リスクとリターン）は面白さの一側面に過ぎず、操作感・物語・世界観・再現・クラフト・音ゲー的快感などの多様性を認識して設計する。

## SOURCE
ゲームの楽しさ＝ゲーム性ではない。 ①操作が楽しいもの、②アドベンチャー/サウンドノベル、③ムービー/ストーリー重視、④版権・キャラクターもの、 ⑤実在モチーフの再現（シミュレーター）、⑥エディット/クラフト系、⑦音ゲー（リズムの原始的快感）。 これらはリスク・リターンのかけひきとは別軸の快感を持つ。

## GENERALIZED
作品が提供しようとしている主要な価値が「かけひき」なのか「鑑賞・シミュレーション・創造」なのかを見極め、後者を無理にゲーム性の枠組みに押し込めて損なわない。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
ゲーム性（勝敗・攻略）至上主義に陥ると、ストーリー体験やシミュレーターとしての純粋な没入感を破壊してしまう。

## Use with context
- Domains: Game Concept, Genre Definition, Narrative Design
- Phases: Pre-production, Feature Prioritization
- Trigger: 新規タイトルのゲームループ策定時、または非アクション要素の仕様策定時

## Agent questions
- この機能は『攻略のかけひき』を意図しているか、それとも『触感・物語・再現の快感』を意図しているか？

## Suggested actions
- ゲーム性以外の快感（環境音、触感、テンポ）を阻害する複雑なシステムを削ぎ落とす。

## Review criteria
- ゲームの根幹の魅力（世界観、操作感）が過剰なルールでスポイルされていないか確認。

## Anti-patterns
- 雰囲気重視のアドベンチャーやシミュレーターに、無理やり唐突な戦闘やQTEをねじ込むこと。

## Tradeoffs and exceptions
- Tradeoff: ゲーム性を排して物語や再現性に寄せると、リプレイ性や勝敗の緊張感は低下する。
- Exception: 競技用e-sportsタイトルなど、純粋な駆け引きのみが求められるジャンル。
