# 能動的実践型チュートリアル（How to Playの短縮と体得）

## Summary
説明書のような長文テキストや無機質な練習場を排し、プレイヤーを能動的に動かしながら短時間で自然にルールとコツを体得させよ。

## SOURCE
初代スマブラの『ターゲットをこわせ!!』はキャラごとの操作習熟を目的とした配置。スマブラSPで操作しながら学べるモードを企画したがスケジュールの都合でデモムービーのみになったことを『一番悔しい』と告白。

## GENERALIZED

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
導入部分の退屈さはプレイヤーの初期離脱（返金・プレイ放棄）の最大要因となるため。

## Use with context
- Domains: All Genres, Onboarding Design
- Phases: Tutorial Design, UX Flow, Level Design
- Trigger: チュートリアル、オンボーディング、操作説明機能の設計・実装時

## Agent questions
- ゲーム開始直後に1分以上の読書やムービー閲覧を強要していないか？
- 操作を学ばせるための専用ステージが、本編の面白さと乖離した無味乾燥な空間になっていないか？
- 『ターゲットをこわせ』のように、そのアクションを使わなければクリアできない楽しいミニ課題になっているか？

## Suggested actions
- 説明ダイアログを削除し、道中に配置されたギミック（段差、障害物、無力な敵）を通過することで自然にアクションを促すレベルデザインへ変更する。

## Review criteria
- コントローラーから手を離して画面を読む時間がなく、操作しながら1〜2分以内に基本ルールを体得できるか。
