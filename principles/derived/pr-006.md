# ゲーム画面即時提示の原則（売りを素早く明確に）

## Summary
販促ムービーでは、長い企業ロゴや前置きムービーを排除し、開始直後の早い段階で実際のゲームプレイ画面を見せよ。

## SOURCE
ゲームを売り込む際、実際に動いているところを確認できるムービーは極めて重要。 ムービーがないゲームはよほどのことがない限り買わない（論外）。 しかし、オープニングや設定説明ばかりで、なかなかゲーム画面に入らないムービーが多すぎる。 Steam等のトップ動画にゲーム画面が一切入っていないケースすらある。これは絶対にやめるべき。 「プレゼンはスピード」。肝心のゲームがどうであるかをすぐに見たい。お話や世界設定はその後でいい。 映像作りをいくら頑張っても映画には及ばないのだから、製品の訴求点（ムービー＜ゲーム本体）をパッと見せるべき。

## GENERALIZED
ユーザーがストアPVを開いた最初の数秒（3〜5秒）で「どんなジャンルで、どう操作して、何が気持ちいいか」を提示する。 ロゴ表示や世界観イントロダクションは最後、または画面隅に小さく置く。

## AGENT
ストアPVの離脱率は最初の数秒が最も高い。インディーゲームにおいて「黒画面に白い企業ロゴ」から始まるトレイラーは即座にスキップされる。

## Why it matters
ユーザーの可処分時間は極めて限られており、ゲーム画面が見えないPVは購入検討の土俵にすら上がらず離脱される。

## Use with context
- Domains: Trailer Production, Marketing, Store Optimization
- Phases: Pre-launch, Marketing
- Trigger: ストア用トレイラー（Steam Trailer 1等）のタイムライン構築時

## Agent questions
- 開始3〜5秒以内にゲームプレイのコアが視認できるか？
- ロゴ表示でユーザーの視聴維持率を下げていないか？

## Suggested actions
- 動画クリップの先頭フレームをスキャンし、ゲーム画面以外の静止ロゴやテキストが3秒以上続く場合に警告を出して先頭をゲームプレイに差し替える。

## Review criteria
- 再生開始から5秒以内に操作画面（実機プレイ）が存在すること。

## Anti-patterns
- 冒頭15秒間、壮大なテキストや風景CG、会社ロゴが続き、ゲーム画面が始まらない。
- プリレンダムービーだけで構成され、UIや実際の操作画面が一切映らない。
