# 高頻度継続更新による情報発信の習慣化（デイリープッシュ）

## Summary
発売前の情報発信は、小出しであっても高頻度（毎日・毎週）で継続的に行い、サイトやアカウント訪問をユーザーの日課にせよ。

## SOURCE
『スマブラDX』では開発現場から画面写真や情報を速報として掲載する『速報スマブラ拳!!』を運営。 『スマブラX』ではなんと平日毎日（週5回）更新を世界6カ国語で展開した（『Smash Bros. DOJO!!』）。 毎日なんらかの変化があることが極めて重要。情報を楽しみにサイトを見に来ることが「日課」になれば効果は絶大。 本来ディレクターがやることではない（最も多忙な時期に監修や執筆に追われるため）。他人に任せられるなら任せたほうが良い。 しかし、ディレクター自らが発信することで、ゲームの本質や奥深い面白さを妥協なく伝えられた。 現代はTwitter等のSNSが中心だが、「ユーザーの日課にする」「定期的に変化を見せる」という本質は変わらない。

## GENERALIZED
情報を一度にドカンと出して終わりにするのではなく、細かく分割して一定リズムで発信し続けることで、コミュニティの関心とエンゲージメントを長期維持する。

## AGENT
現代のインディー開発における「#ScreenshotSaturday」や日々の開発進捗ポスト、Discordでの開発日誌更新の理論的根拠となる。

## Why it matters
発売前の長期にわたる開発期間中、ユーザーの熱量を維持し続け、発売日に向けた期待のピークを構築できる。

## Use with context
- Domains: Community Management, Social Media Strategy, Public Relations
- Phases: Production, Pre-launch
- Trigger: 発売前プロモーション計画、SNSコンテンツカレンダー作成時

## Agent questions
- ユーザーが日常的に接点を持てる継続的な小規模コンテンツが準備されているか？

## Suggested actions
- ゲーム内の要素（キャラ、技、BGM、ステージ、UI小ネタ）を分解し、日次/週次の告知ドラフトを自動編成する。

## Review criteria
- 発信スケジュールに数週間以上の空白期間が存在しないこと。

## Anti-patterns
- 発表時にPVを1本公開した後、発売直前まで一切の情報を出さず放置する。
- 更新頻度が完全に不定期で、ユーザーが追いきれなくなる。
