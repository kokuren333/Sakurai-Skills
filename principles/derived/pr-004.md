# 公式情報基盤（ウェブサイト/旗艦拠点）の階層化設計

## Summary
SNS全盛期であっても、包括的かつ正確な一次情報を集約・整理した旗艦拠点（公式サイト）を整備し、作品規模に応じた深度を持たせよ。

## SOURCE
SNSの短い情報発信が現代には合っているが、大手の作品から公式サイトが消えることはない。 まとまった情報が正しく発信される旗艦となる場所は不可欠。 初代『スマブラ』発売前、関係者にゲーム内容が理解されず偏見（任天堂キャラが殴り合うのはけしからん、格ゲーより浅い）を持たれた苦い経験から、自らHTMLを書いて『スマブラ拳!!』を立ち上げ、駆け引きや操作法の手引きを公開した。 『スマブラSP』では、ファイター、あそびかた、ステージ、アイテム、サウンド、ムービー、ブログ（スマブロ）など多層的な構成を持つ巨大サイトを構築。

## GENERALIZED
SNSは「流れていくプッシュ型情報」、Webサイトは「構造化されたストック型一次情報」。 新規性が高すぎて誤解されやすいゲームほど、システムの深層や面白さを論理的に解説する公式アーカイブが必要。

## AGENT
インディーゲームであっても、Notionや独自ドメインでのプレスキット／マニュアル／FAQなどの「正確な一次情報ハブ」が存在しないと、コミュニティやメディアが誤った解釈を拡散する。

## Why it matters
SNSの断片情報だけではゲームの全貌や深みが伝わらず、第一印象の偏見（食わず嫌い）を打破できない。

## Use with context
- Domains: Web Design, Community Management, Technical Writing
- Phases: Pre-launch, Post-launch Operations
- Trigger: 広報ハブ（プレスキット、Webサイト、Wiki）の構築・更新時

## Agent questions
- このゲームの「ルールの根幹」と「奥深い駆け引き」を解説するコンテンツが含まれているか？

## Suggested actions
- ゲーム設計ドキュメントから「システム解説」「キャラクター一覧」「操作手引き」を自動抽出し、Web用ドキュメント（Markdown/HTML）を生成する。

## Review criteria
- 外部の人間（メディアやユーザー）が一次情報源として参照できる網羅性と正確性を備えていること。

## Anti-patterns
- SNS発信のみに頼り、仕様やキャラ一覧を体系的に確認できる公式Webページを用意しない。
- Webサイトの更新を広報業者に丸投げし、ゲームの奥深い駆け引きが伝わらない表面的なカタログにする。
