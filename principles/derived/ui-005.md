# メニュー項目の同語反復を排した客観的ヘルプ文

## Summary
メニューのヘルプ文では項目名と同じ言葉を使わず、その機能の意味や目的を別の言葉で具体的に噛み砕いて説明する。

## GENERALIZED
メニューのヘルプ文では項目名と同じ言葉を使わず、その機能の意味や目的を別の言葉で具体的に噛み砕いて説明する。

## AGENT
Apply as a contextual review heuristic, not an absolute rule.

## Why it matters
同語反復の説明文は画面の貴重な領域を浪費し、機能の意味が分からず困っているプレイヤーを完全に放置することになるため。

## Use with context
- Domains: Menu Design, Technical Writing, Localization
- Phases: UI Design, Text Asset Creation, Review
- Trigger: メニューテキスト、ローカライズテーブル、設定項目の作成・編集時

## Agent questions
- LabelとDescriptionが同語反復になっていないか？
- ユーザー視点のベネフィットが記述されているか？

## Suggested actions
- テキストリソースから「項目名文字列」が「ヘルプテキスト」に含まれている箇所を検出し、リライト案を提示する。
- 専門用語を平易な表現に置換する辞書フィルターを適用する。

## Review criteria
- すべてのメニュー項目に操作結果を予見できる説明文が存在すること。
- 項目名と同じ単語のみで構成された無意味な説明文がゼロであること。

## Anti-patterns
- 「サウンド」→「サウンドの設定をします」、「クレジット」→「クレジットを見ます」などのトートロジー（同語反復）。
- 「アンチエイリアシング」「オクルージョン」などのグラフィック専門用語を補足説明なしで並べること。

## Tradeoffs and exceptions
- Tradeoff: 説明を噛み砕くほどテキスト文字数が増えるため、画面レイアウトの制約や多言語化時のオーバーフローに配慮が必要。
- Exception: 誰でも100%誤解の余地がない極小規模な固定メニュー（「Exit」「Quit」等で画面サイズが極端に狭い場合）。
