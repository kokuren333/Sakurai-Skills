# 監修依頼の即日返答とディレクターの『ノー監修集中タイム』確保

## Summary
チームからの監修依頼メールはその日のうちにすべて返し切り、自身の集中作業時間はスケジュールを区切ってブロックする。

## SOURCE
ディレクター宛の監修依頼メールは毎日大量に届くが、『必ずその日のうちに返し切る』ことをモットーとする。キーマンの判断遅延はそのままチーム全体の作業停止（待機時間）につながるためである。ただし常にメール待ち状態になると自身の仕事が進まないため、午前中などを『ノー監修タイム』として設定し、自分の作業時間を確保する。

## GENERALIZED
意思決定者のブロッキングは組織全体のクリティカルパスとなる。非同期リクエストのターンアラウンドタイム（TAT）を24時間以内に抑えつつ、コンテキストスイッチの負荷を軽減するために『集中時間（Deep Work）』と『対応時間（Reactive Work）』をタイムボックスで明確に分離する。

## AGENT
リードエージェントやオーケストレーターがサブタスクの承認待ちを滞留させないためのキュー管理アルゴリズム（即時バッチ処理フェーズと独立推論フェーズの分離）に応用できる。

## Why it matters
判断を待つ間、スタッフの案件は宙に浮き、作業効率が激減する。返答を翌日に先送りすると未読の山が雪だるま式に膨らみ、判断自体の質も低下する。

## Use with context
- Domains: Project Management, Leadership, Productivity
- Phases: Production, Alpha, Beta
- Trigger: レビュー要求・承認リクエストの受信時

## Agent questions
- この承認待ちによって後続タスクがブロックされているか？
- 現在エージェントは集中処理モード（Deep Work）か、トリアージモード（Reactive Work）か？

## Suggested actions
- ブロッキングなレビュー要求はキューの最優先に配置し、タイムボックス終了時に一括判定・返答する。
- 即答できない場合でも『24時間以内に回答する』等のステータス更新を即時発行する。

## Review criteria
- 未読/未処理の承認キューが24時間以上滞留していないこと。

## Anti-patterns
- 『今度でいいや』と返答を翌日以降に先送りし、未読メールの山に埋もれて催促されるまで放置する。
- チャットで四六時中ランダムに話しかけられ、1日中細切れの対応だけで終わってしまう。
