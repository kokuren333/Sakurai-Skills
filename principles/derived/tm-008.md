# 対戦バランス調整における専任モニター制と個性の維持

## Summary
対戦バランスはプレイ時間の長い専任モニターの膨大な対戦分析に基づき、極端な弱体化を避けて個性を生かした調整を行う。

## SOURCE
開発者自身のプレイ時間はヘビープレイヤーに遠く及ばない。スマブラXまでは桜井氏の独断で調整していたが、for/SPでは専任のモニター班を強化し、膨大な対戦データと勝率分析を元に調整した。桜井氏が口を挟むのは『個性を殺してしまいそうになった時』であり、全ファイターの勝率を47%〜51%台の狭い範囲に収めつつ、尖った強みや個性を残すことを目指した。

## GENERALIZED
複雑系のゲームバランス調整は直感ではなく客観的テレメトリと熟練者の反復試行データに基づくべきである。しかし、数値を平坦に均しすぎるとゲームが退屈になるため、統計的公平性を担保しつつ『キャラクター固有の強み・弱み（非対称性）』を死守する境界線を設定する。

## AGENT
強化学習エージェントやボット対戦による自動シミュレーションで勝率・使用率データを収集しつつ、パッチ適用時に全パラメータの標準偏差が縮まりすぎていないか（個性が消えていないか）を検証するアルゴリズムを組む。

## Why it matters
開発者の主観だけで調整すると、特定プレイスタイルに偏り、ユーザーのやり込みに耐えられない。また、批判を恐れて尖った要素を削りすぎると、どのキャラクターも同じような凡庸なゲームになる。

## Use with context
- Domains: Game Balance, Data Analysis, Combat Design
- Phases: Alpha, Beta, Live Tuning
- Trigger: 対戦キャラクター・武器・スキルのパラメータ調整時

## Agent questions
- 変更対象のパラメータは、キャラクターのコアコンセプト（一番の魅力）に直結しているか？
- 十分なサンプル数の対戦シミュレーションデータ（勝率・有利不利マトリクス）に基づいているか？

## Suggested actions
- パラメータ調整を行う前に、自動対戦ボットまたはテストログから勝率・ピック率のヒートマップを出力する。
- 勝率外れ値のユニットに対して、長所（攻撃力など）を削るのではなく、短所（硬直、クールダウン等）を調整する案を優先提示する。

## Review criteria
- 全ユニット間の勝率格差が許容レンジ内に収まっていること。
- ユニットごとの性能パラメータの差異（分散）が一定以上維持されていること。

## Anti-patterns
- ユーザーフォーラムの声の大きい意見や、開発者自身の得意不得意だけでパラメータを頻繁に変更する。
- バランスを取るために、全キャラのリーチ・発生フレーム・移動速度を横並びにする（平均化の罠）。
