# 製品像の厳密一致原則（ミスマッチの完全排除）

## Summary
パッケージ、タイトル、広告等で提示する製品像は、実際のゲームプレイの感触と絶対に乖離させてはならない。

## SOURCE
ゲームは遊ぶまで中身が分からないため、パッケージやPVで知ることになる。 ゲーム内容でどんでん返しや意表を突きたい場合でも、「商品像と違うもの」を出してはならない。 例え話として「バナナを買ったりんごの味がした」ではダメ。 買おうとした時のイメージと、ゲーム内で得られる楽しさは絶対に合致していなければならない。 乖離があると、本来のターゲット層に届かないばかりか、間違えて買った人を失望させる。

## GENERALIZED
サプライズ（驚き）とミスリーディング（誤導）を混同してはならない。 ジャンル、ゲームループ、難易度感、世界観のトーン＆マナーは、第一印象とプレイ実態を100%整合させる必要がある。

## AGENT
いわゆる「広告詐欺（Fake Ads）」や「過剰演出PV」に対する強い戒め。 短期的なクリック・購入を誘発しても、返金や低評価レビューの嵐となりIPを破壊する。

## Why it matters
ミスマッチは低評価レビュー、高返金率、口コミの悪化を招き、スタジオの信頼を失墜させる。

## Use with context
- Domains: Store Page Setup, Key Visual Design, Copywriting
- Phases: Pre-production, Marketing, Release
- Trigger: ストアページ（Steam/ストアフロント）のメタデータ作成、キーアート作成、PV構成時

## Agent questions
- このキーアート/説明文を見たユーザーは、ゲームプレイのコア（Core Loop）を誤解なく想像できるか？

## Suggested actions
- 生成されたストア用説明文と実際のゲームプレイループを照合し、語弊のあるジャンル名や誇大表現を検出し修正する。

## Review criteria
- プロモーション素材から推測されるプレイスタイルと、実ゲームのコアメカニクスが完全一致していること。

## Anti-patterns
- ほのぼの農場ゲームに見せかけて、実際はグロテスクなホラー・ゾンビゲームである（動画内のイラスト例）。
- 美麗な3Dムービーばかり見せて、実際の2Dパズル画面を一切見せない。
