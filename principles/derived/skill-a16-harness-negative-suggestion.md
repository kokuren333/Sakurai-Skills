# 暗示の力（逃走本能を活用した締切突破）

## Summary
作業の推進力として『目標への接近』だけでなく『迫り来る締切や破滅からの逃走』という強烈な自己暗示を活用せよ。

## SOURCE
桜井氏は中学時代、徒競走でビリだったが『後ろから3mの巨大重機が追ってくる』と自己暗示をかけて猛ダッシュし一等賞を取った。何かに向かうより、何かから逃げる暗示の方が効果的。

## GENERALIZED
人間の認知的バイアス（損失回避性および防衛的ペシミズム）をテコにして、パーキンソンの法則を打ち破る強制的な推進力を生み出す。

## AGENT
スプリント終了直前やマイルストーン前の開発において、エージェントがタスクのデッドラインを短く設定し、緊急度を高めて処理速度をブーストさせる戦略。

## Why it matters
「いつでもやっていい」「いつか終わればいい」という緩い目標設定は、作業の際限ない遅延とリソースの浪費を招くため。

## Use with context
- Domains: time_management, execution, focus
- Phases: implementation, sprint_execution
- Trigger: タスクの進行速度が低下しているとき、または厳格なマイルストーンが設定されたとき

## Agent questions
- 「まだ時間がある」と油断して、作業ペースを落としていないか？
- 直近のデッドライン（人工的な締切）を設定し、そこから全力で逃げ切る緊張感を作れているか？

## Suggested actions
- 最終締切の手前に『人工的な中間デッドライン』を設定し、カウントダウンタイマーを可視化する
- 「あと○時間で終わらなければこの機能はカットされる」という制限を設け、集中力を強制的に引き上げる

## Review criteria
- 設定された人工デッドライン内にタスクが完遂されていること
- 漫然とした作業進行が排除され、初速とトップスピードが維持されていること

## Anti-patterns
- 「夏休みの宿題は最後の日にやる」感覚を放置し、締切直前まで着手しない
- 締切を何度も後ろに倒し、緊張感のない開発環境を常態化させる

## Tradeoffs and exceptions
- Tradeoff: 過度な恐怖・ストレスの自己暗示は長期的なメンタルヘルスを損なうため、短期的なスプリントに限定して適用すべき。
- Exception: 長期的構想を練るリサーチ期間や、心身のリカバリーを目的とした休暇期間。
