# 異種世界観キャラクターのタッチ統合（リファインの5原則）

## Summary
コミカル系とリアル系のキャラクターが同一画面で共闘する際、①彩度の抑制 ②テクスチャの描き込み加減 ③等身の微調整 ④必要に応じたリファイン ⑤実在しそうな表現（瞼や歯の噛み合わせ）の5要素でタッチを統一する。

## SOURCE
【明示】『スマブラ』のように世界設定の異なるキャラが一堂に会する場合、そのまま並べると『アニメと実写が戦っている』ような激しい違和感が出る。これを防ぐための5つの手法：①彩度を控えめにして環境光を馴染ませる（ネスの服等）、②テクスチャをほどよく描き込む（ソニックの毛並み追加、サムスの重み軽減）、③等身を工夫する（ベヨネッタやカズヤの等身微調整）、④必要に応じたリファイン（オリマーのスーツディテール、アイスクライマーの靴底スパイク）、⑤実際にありそうな表現（ヨッシーやドンキーの目を漫画的白目閉じではなく瞼で閉じる、歯の噛み合わせをリアルにする）。

## GENERALIZED
【一般化】クロスオーバー作品や多様なアセットストア素材を統合する際、モデルのトポロジーやテクスチャのリアリティ水準（情報密度・マテリアル反応・骨格比率）の基準線（アンカー）を明確に定め、双方から歩み寄らせる。

## AGENT
【補足】IPホルダーの監修を受けつつ、ゲーム全体の統一シェーダー環境（PBRパイプライン）で破綻しないよう、マテリアルのアルベド彩度やディテールノーマルを調整する。

## Agent questions
- 画面内の全キャラクターの情報密度（テクスチャ解像度・ディテール量）が揃っているか？
- ライティングに対する反応（スペキュラ、環境光の馴染み）が一致しているか？

## Suggested actions
- マテリアルの彩度ヒストグラムを解析し、突出して高彩度なアセットの彩度を自動抑制する。
- フラットなアセットに対してマイクロサーフェス（微細ノーマルマップ）を追加する提案を行う。

## Review criteria
- 同一のバトルフィールドに全キャラクターを並べたスクリーンショットにおいて、特定のキャラクターだけが別のゲームから貼り付けられたように見えないこと。

## Anti-patterns
- 原作の公式イラストそのままのテクスチャを貼り、リアルな背景の中でキャラクターだけが浮き上がっている。
- コミカルキャラの質感表現を拒絶し、プラスチックのような均一な質感のまま放置する。
