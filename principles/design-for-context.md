# Apply principles in project context

## Summary
Choose principles by genre, audience, phase, constraints, and requested review scope.

## SOURCE
The user-provided repository brief requires contextual application and preservation of exceptions. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/00-repository-completion-brief.md).

## GENERALIZED
State assumptions, select relevant principles, and name tensions before recommending changes.

## AGENT
Do not turn a heuristic into an absolute rule without project evidence.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
