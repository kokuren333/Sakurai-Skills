# Make action results readable through feedback

## Summary
Align visual, audio, motion, and interface feedback with action and consequence.

## SOURCE
Specification and feel materials describe response and feedback as parts of game feel. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/D-specification.md).

## GENERALIZED
Check timing, location, intensity, consistency, and competing signals.

## AGENT
Respect sensory accessibility settings and avoid overwhelming the play space.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

- What player-visible outcome is at stake?
