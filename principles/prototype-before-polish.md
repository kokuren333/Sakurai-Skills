# Validate the loop before investing in polish

## Summary
Test whether the core loop works with low-cost assets before scaling content or presentation.

## SOURCE
Source materials emphasize making and testing the central experience early. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/C-planning-design.md).

## GENERALIZED
State a hypothesis, prototype the minimum loop, observe players, decide the next change.

## AGENT
Polish can itself be part of the hypothesis for presentation-led experiences.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
