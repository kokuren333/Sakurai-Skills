# Player-first decisions

## Summary
Favor player value and understanding among viable choices.

## SOURCE
The source material frames player experience as the reason for production decisions. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/A-work-attitude.md).

## GENERALIZED
Evaluate decisions by the experience they create for the intended player.

## AGENT
Use as a decision question, not a veto over safety, accessibility, cost, or project goals.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
