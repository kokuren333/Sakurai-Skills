# Prototype uncertain interactions early

## Summary
Use the cheapest representative implementation to learn about core interactions before polishing dependent work.

## SOURCE
Technical material recommends provisional models and rapid adjustment of movement response. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/K-programming-technical.md).

## GENERALIZED
Prioritize experiments that resolve high-impact uncertainty.

## AGENT
A prototype is not proof of production readiness or a substitute for safety and platform checks.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
