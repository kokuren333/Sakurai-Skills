# Remove friction that does not serve the experience

## Summary
Keep waits, repeated inputs, and interruptions only when they create meaningful anticipation, comprehension, or choice.

## SOURCE
UI material includes faster selection, skipping non-play time, and player control over text pace. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/J-ui.md).

## GENERALIZED
Trace player tasks and distinguish purposeful pacing from accidental delay.

## AGENT
Friction can be intentional for suspense, deliberation, accessibility, or narrative effect.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
