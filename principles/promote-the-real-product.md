# Communicate the shipped experience accurately

## Summary
Align public claims and promotional material with the actual product and current state.

## SOURCE
Publicity material stresses truthful communication and product/promotion alignment. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/L-publicity.md).

## GENERALIZED
Verify footage, claims, platform availability, and caveats before publication.

## AGENT
A focused slice is acceptable if it does not imply unavailable features.

- Project scope includes this decision and context supports the intended outcome.
