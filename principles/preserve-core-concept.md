# Preserve the core concept

## Summary
Judge changes by whether they strengthen, clarify, or dilute the defining experience.

## SOURCE
The source material stresses holding a project core concept amid competing ideas. This is a thematic attribution to supplied intermediate material, not a verified quotation or timestamp. See [preserved source](../sources/raw/A-work-attitude.md).

## GENERALIZED
Use the concept as a filter for scope and change decisions.

## AGENT
Revise the concept when evidence shows it is not working; preservation is not resistance to evidence.

## Apply when
- Project scope includes this decision and context supports the intended outcome.

## Questions
- What player-visible outcome is at stake?
- What evidence supports this diagnosis?
- Which constraints or countervailing principles matter?

## Review criteria
- Tie advice to evidence or explicit assumptions.
- State tradeoffs, exceptions, and a small validation step.
