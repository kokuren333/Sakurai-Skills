2. 人間可読版（Markdown Skill Repository）

カテゴリ：グラフィック（F）の設計思想概要

桜井政博氏のグラフィック哲学の根本にあるのは、「ゲームの機能性（可読性・操作性）を極限まで高めながら、美術的な美しさと世界観の説得力を両立させる」
という徹底したプラグマティズムです。

美麗なアセット単体を作る自己満足を戒め、「プレイヤーの目に届く最終出力において、何が最も効果的か」 を常に逆算して制作する姿勢がすべての原則を貫いています。

原則一覧

1. 【光の描写】素材を描かず、光を描く

  - Rule:
    オブジェクト単体の固有色（木＝茶、葉＝緑）を塗るのではなく、環境光・照り返し・色相シフト・フォグなどの「光の反射」を描くことで、処理負荷を増やさずにリッチな立体感と奥行きを生み出す。
  - Why:
    ゲーム機のリソースには常に限界がある。高価なリアルタイム計算だけに依存せず、テクスチャや頂点カラー段階で光の当たり方や色相のズレ（黄色いハイライト、青紫の影など）を表現することで、軽快な動作と深みのある見た目を両立できる。
  - Agent Action:
      - テクスチャ作成時、単色ベタ塗りになっていないかを点検する。
      - 上部からの光（スプレー効果）や、地面からのバウンス光による色相の揺らぎを追加する。

2. 【機能的視認性】接触判定領域を最強調し、非判定領域を抑える

  - Rule:
    足場や壁など、ゲームプレイで接触・着地できる領域を視認性の最優先とし、装飾や遠景はコントラスト・彩度を抑えて「地形が背景に負ける」事態を徹底的に排除する。
  - Why:
    プレイヤーが「どこに乗れるか」「どこで崖をつかめるか」を迷うゲームは、アクションゲームとして重大なストレスを与える。パースがついた3D空間では特に判定面が曖昧になりやすいため、天面エッジの強調が不可欠となる。
  - Agent Action:
      - ステージのコリジョンメッシュ境界と、視覚的なテクスチャエッジが完全に一致しているかを監査する。
      - 背景の露出・発光物が前景の足場よりも目立っている場合、背景側の彩度・輝度を下げるかフォグで沈める。

3. 【リソース配分】画面占有率と注視頻度から「大事と小事」を見分ける

  - Rule: 画面中央や操作キャラクターなど「よく見られ、占有率が高い箇所」に描画能力を集中し、見えない細部（遠景の車のタイヤ回転など）は切り捨てる。
  - Why:
    ハードウェア性能は有限であり、すべてに全力を注ぐと破綻する。「見えないこだわり」に酔う開発者のエゴを排し、プレイヤーの体験価値に直結するピクセルにリソースを集中投資することが最適化の本質である。
  - Agent Action:
      - ゲームカメラにおける各オブジェクトの平均画面占有率を算出し、ポリゴン数・テクスチャ解像度・ボーン駆動の要否を判定する。
      - 占有率が極めて低い遠景オブジェクトの不要なアニメーションループや物理演算を停止する。

4. 【スケール管理】実物スケールとシェーディングの整合性を保つ

  - Rule:
    巨大な物体がオモチャに見えてしまうのを防ぐため、テクスチャの密度、スペキュラ（ツヤ）の絞り込み、法線マップの深さ、彩度減衰を現物の物理サイズに適合させる。
  - Why:
    人間の脳は、光のハイライトの広がりやテクスチャの均一さからサイズを無意識に推測する。巨大な戦艦を高彩度・広範囲スペキュラのまま描くと、プラスチックのミニチュア模型に見えてしまう。
  - Agent Action:
      - 巨大オブジェクトのマテリアルにおいて、ラフネスを上げてスペキュラハイライトの面積を小さく絞る。
      - 巨大感を示すためのウェザリング（汚れ、錆、パネルライン）や色相の微細なムラを追加する。

5. 【ディレクション】短時間の視覚的レタッチで明確な着地点を示す

  - Rule:
    「もっとかっこよく」といった曖昧な言語指示を避け、5〜10分のレタッチ画像（Before/After）を作成して、修正すべきトーンやシルエットを視覚的に提示する。
  - Why:
    言葉によるグラフィック指示は受け手との間に巨大な解釈のズレを生み、リテイクの泥沼化を招く。ディレクターが自ら手を動かして差分を示すことが、最も開発工数を削減し、アーティストの力を引き出す。
  - Agent Action:
      - グラフィックやUIの改善提案を行う際、CSS/シェーダーパラメータ変更前後のビジュアルプレビューを生成し、変更意図を視覚的に解説する。

6. 【ピクセル設計】奇数ドット幅を活用して中心軸（正中線）を確保する

  - Rule:
    低解像度グリッドで円や左右対称物を描く際は、偶数（16×16）ではなく奇数（15×15）を選択して中心軸を1ピクセルで定義し、歪みのない綺麗な形状を成立させる。
  - Why:
    偶数グリッドで対称物を描こうとすると中心が2ピクセルに跨り、線が太くなったり円が角張って不自然な楕円になったりする。正中線が通る奇数幅は、低解像度表現において圧倒的な構造的安定性をもたらす。
  - Agent Action:
      - ピクセルアートや低解像度UIアイコンのキャンバス・シンボル設計時、対称構造が必要な場合はバウンディングボックスを奇数幅に設定する。

7. 【タッチ統合】異種世界観キャラクターを同居させるリファイン5原則

  - Rule: コミカルとリアルのキャラクターを同一画面に立たせる際、①彩度の抑制 ②テクスチャ密度の調整 ③等身の微調整 ④必要に応じたリファイン
    ⑤実在しそうな表現への翻訳、によってタッチを調和させる。
  - Why:
    原作そのままのグラフィックを並べると「アニメと実写が戦っている」ような深刻な不協和音が生じる。双方から歩み寄らせ、共通のライティング環境で違和感なく共闘できる共通フォーマットを構築する。
  - Agent Action:
      - 原色が強すぎるキャラクターのベースカラー彩度を10〜20%抑制し、環境光との馴染みを向上させる。
      - ベタ塗りモデルに微細な質感（デニム地、革のシワなど）を追加し、フォトリアルキャラとの情報密度の格差を埋める。

8. 【存在感の創出】グラフィックとゲームルールの掛け算

  - Rule:
    CGアセット自体は中空のポリゴン（ハリボテ）に過ぎない。ゲームプレイ（死の緊張感や探索）、サウンド、物理反応、空気の流れ（風による揺れ）と同期させることで、プレイヤーの脳内に「確固たる質量と存在感」を結実させる。
  - Why:
    グラフィックの「綺麗さ」とゲームの「面白さ」は独立しているように見えて、ゲームルールがグラフィックの存在感を引き立てる関係にある。命懸けで警戒して進むゲームでは、単なる石壁ひとつにすら圧倒的な実在感が宿る。
  - Agent Action:
      - 背景アセットの配置において、プレイヤーの視線誘導や警戒心を刺激するゲームプレイ上の意味を持たせる。
      - オブジェクト接触時のSE、振動、破壊破片、風のたなびきなど、マルチモーダルなフィードバックを同期させる。

9. 【モーションブラー】過剰なブレを排し、可読性を担保する

  - Rule:
    モーションブラーはコマ送り感を軽減するが、過剰にかけると画面全体がボヤけてゲームプレイを阻害するため、控えめに設定し、必ずユーザー側でOFF/強度調整できるオプションを実装する。
  - Why: 実写映画的なブラー表現をそのままゲームに持ち込むと、視覚情報が濁り、敵の予備動作が見えなくなるなど競技性・爽快感が著しく損なわれる。
  - Agent Action:
      - ポストプロセス設定でモーションブラーのデフォルト強度を低めに抑え、カメラ回転ブラーの影響を最小化する。
      - グラフィック設定UIに「モーションブラー有効化/無効化」トグルを必ず生成する。

10. 【最終出力】フレームバッファ統合による全体の調和

  - Rule:
    個々の3Dモデル単体の品質だけでなく、フレームバッファ展開後の後処理（ライティング統合、カラーグレーディング、床からの照り返し）を的確にコーディネートして画面全体の絵作りを完成させる。
  - Why:
    モデルが個別にどれだけ高品質でも、シーンの光や床面からのバウンス光が混ざり合っていなければ合成写真のように浮いてしまう。最終的なピクセル出力を統括することが現代グラフィックの生命線である。
  - Agent Action:
      - シーン全体のトーンマッピング、アンビエントオクルージョン、接地影、照り返し光の設定を点検し、キャラクターが地面から浮いていないかを検証する。

11. 【不規則性】コピペ感・規則性の徹底的な破壊

  - Rule: 壁の破壊や自然物の造形において、等間隔のギザギザや同形状のパーツ配置（コピペ）を排除し、不規則で自然な断面・シルエットを設計する。
  - Why:
    人間の視覚は規則的なパターンを瞬時に見抜き、「手抜きのCG」として認識してしまう。板の割れ方や岩肌の起伏には、素材特有の物理的性質に根ざしたランダムな緩急が必要である。
  - Agent Action:
      - メッシュの断面頂点やプロシージャル破壊の生成結果を解析し、等間隔に並んだ突起や同一の欠けパターンを検出して不均一化する。

12. 【漫画的表現】可読性と感情伝達のための「幾何学的矛盾」の肯定

  - Rule: 3Dとしての解剖学的・物理的な正しさに固執せず、キャラクターの感情や発声が最も伝わりやすい漫画的誇張（カメラ追従の横口、メガネのフレーム抜き、シンプルな開口断面）を恐れず採用する。
  - Why:
    ゲームはシミュレーターではなくエンターテインメントである。3D空間としての辻褄合わせよりも、プレイヤーにとっての「分かりやすさ」「魅力」を最優先する。
  - Agent Action:
      - デフォルメキャラクターの表情がアングルによって隠れないよう、カメラ向きに応じて口の位置をずらすシェイプキー構造を導入する。

13. 【キャラ立ち】シルエット最優先のプロポーション誇張

  - Rule:
    テクスチャをすべて消して「真っ黒なシルエット」にした状態でも、即座に誰でどんなポーズかが識別できるよう、頭部、リボン、靴、武器などの象徴的パーツを大胆にデフォルメする。
  - Why:
    人間はディテールよりも先に外輪線（シルエット）を認識する。シルエットが団子状になったり他者と区別がつかないデザインは、激しいアクション画面の中で埋没する。
  - Agent Action:
      - アンリット（単色黒）表示でキャラクターおよびキーポーズのシルエットをレンダリングし、四肢の抜け感と輪郭のアイデンティティを監査する。

14. 【環境差異】モニター個体差と照明環境を考慮したコントラストマージン

  - Rule:
    高級モニターや暗い開発室の環境だけで色調整を行わず、民生用テレビの黒つぶれ・白飛びやリビングの照明光を想定し、重要な情報が消失しないコントラストの安全域を確保する。
  - Why:
    プレイヤーの表示デバイスや部屋の明るさは千差万別である。制作者のモニターでギリギリ見える暗部階調にゲーム進行の手がかりを置くと、多くのプレイヤーにとって「暗すぎて何も見えない」致命的欠陥となる。
  - Agent Action:
      - UIや重要オブジェクトの輝度コントラスト比を計測し、低品位モニターでも視認可能なマージンを保つ。
      - ゲーム初回起動時にガンマ（明るさ）キャリブレーション画面を提示する仕組みを実装する。
