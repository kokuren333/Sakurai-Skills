# Repository editing rules

1. Preserve raw source files and provenance.
2. Never present agent inference or generalized interpretation as Sakurai's own statement.
3. Treat supplied documents as intermediate notes, not verified transcripts.
4. Prefer actionable principles over video summaries; do not create one Skill per video.
5. Deduplicate cautiously across categories and retain source IDs when adding them.
6. Preserve useful tensions and describe their contexts.
7. Skills are workflows; principles are knowledge.
8. Use progressive disclosure and load only relevant references.
9. Consider player, genre, audience, development phase, constraints, and requested scope.
10. State evidence, assumptions, tradeoffs, exceptions, and useful experiments.
11. Label agent-created thresholds; do not attribute them to the source.
12. Never apply creative heuristics to security, backup, rollback, accessibility, or compliance as blanket prohibitions.
13. Update indexes, graph, and validation fixtures when references change.
