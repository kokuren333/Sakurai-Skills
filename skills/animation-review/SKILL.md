---
name: animation-review
description: Review animation timing, pose readability, motion continuity, and action alignment.
---

# Use when
Movement, anticipation, impact, locomotion, facial performance, or animation-to-gameplay alignment is in question.

# Procedure
1. Identify the gameplay event and information the motion must communicate.
2. Inspect key poses, timing, trajectory, silhouette, transitions, and camera framing.
3. Compare animation with input acceptance, active frames, collision, and recovery where evidence exists.
4. Load matching `animation` and `gameplay` catalog records.
5. Specify whether a change needs animator review or in-build evaluation.

# Output
Observed motion, evidence source, communication gap, tradeoff, suggested edit, and build test.
