---
name: scope-review
description: Review feature scope, cuts, dependencies, and fit with the intended game promise.
---

# Use when
The feature list, schedule, production plan, or concept boundaries need prioritization.

# Procedure
1. State the core promise and the player value of each contested item.
2. Map cost, dependencies, uncertainty, risk, and opportunity cost.
3. Identify cuts that preserve the experience and obligations that cannot be traded away.
4. Load relevant `game_design`, `team`, and `creator_workflow` principles.
5. Recommend a reversible decision or a validation that reduces uncertainty.

# Output
Keep/cut/defer candidates, rationale, affected risks, owners, and revisit evidence.
