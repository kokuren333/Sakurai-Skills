name: controls-review
description: Inspect input mapping, control response, timing, and accessibility in context.
---

# Use when
Inputs feel inconsistent, controls are being specified, or remapping/input support is under review.

# Procedure
1. Identify device, platform, player skill assumptions, action intent, and evidence type.
2. Trace input acceptance, buffering, acceleration, cancellation, feedback, and recovery from source/build evidence.
3. Compare control naming and layout with player expectations; inspect remapping and alternate input needs.
4. Load matching `gameplay`, `specification`, or `game_design` principles from `principles/catalog.json`.
5. State what requires hands-on build verification and propose a focused test.

# Output
Input trace, evidence and limits, risk, tradeoff, proposed change, and validation.
