---
name: ui-ux-review
description: Review interface clarity, navigation friction, player control, and onboarding.
---

# Use when
Reviewing menus, HUD, settings, text, tutorials, prompts, or accessibility-related interaction.

# Procedure
1. Identify player task, frequency, context, and input method.
2. Trace the shortest successful path and identify confusion or repeated work.
3. Check focus, feedback, terminology, error recovery, skip/pause, remapping, and text pace as applicable.
4. Distinguish purposeful pacing from avoidable friction.
5. Suggest a small usability test with the intended audience.

# Relevant principles
`reduce-unnecessary-friction`, `protect-player-from-dev-constraints`, `make-onboarding-legible`, `player-first`, `design-for-context`.

# Output
Task path, evidence, comprehension/friction findings, exceptions, suggested adjustment, and verification.

# Guardrails
Consider genre, localization, input, accessibility, and platform constraints.
