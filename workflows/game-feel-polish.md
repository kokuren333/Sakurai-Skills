# Game-feel polish
1. Capture target build, device, action, expected behavior, and actual observation.
2. Trace input, response timing, animation, collision, VFX, audio, camera, and recovery.
3. Identify the single strongest evidenced mismatch; do not infer feel from code alone.
4. Change one bounded variable or signal where practical.
5. Compare under the same conditions and check accessibility and regression impacts.
